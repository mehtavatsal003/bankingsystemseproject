# Banking System

This is a browser-based implementation of the banking-system SRS in `SE_NISHA.pdf`.

## Features

- Customer registration and login
- Admin and customer roles
- Account dashboard with balance, account number, status, and monthly activity
- Deposit and withdrawal operations with balance validation
- Account-to-account transfers
- Transaction statement with search, date-range filters, opening/closing balance summary, and print support
- Loan application submission and admin approval
- Support-ticket creation and admin resolution
- Local browser persistence using `localStorage`
